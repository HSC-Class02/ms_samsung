# 삼성전자 재무분석 보고서

- 분석 대상: 삼성전자(005930), 연결재무제표(CFS)
- 자료 출처: 금융감독원 OpenDART 정기보고서
- 작성 상태: **데이터 검증 로직 수정 완료, 수정된 파이프라인 재실행 전**
- 단위: 금액은 조 원, 비율은 %

## 1. 분석 목적

2010년 이후 삼성전자의 사업보고서·반기보고서·분기보고서에 공시된 주요 재무 수치를 이용해 매출 성장, 수익성, 재무 안정성, 유동성을 분석한다. 보고서 수치의 정확성을 확보하기 위해 재무제표 계정 매핑과 회계 등식 검증을 먼저 수행한다.

## 2. 기존 데이터 품질 점검 결과

기존 대시보드 데이터에서 회계적으로 일관되지 않는 값이 확인되어, 기존 숫자를 이용한 실적 해석은 보류한다.

- 2025년 자산총계는 약 566.9조 원으로 표시되지만 자본총계는 약 4.4조 원으로 기록되어 있었다.
- 일부 연도에는 순이익이 영업이익과 동일하거나, 유동자산·현금성자산 등 일부 항목이 비정상적으로 표시되었다.
- 이는 화면 표시 문제가 아니라 원천 데이터의 계정 매핑·선택 방식에서 생길 수 있는 문제이므로 기존 비율을 재무 분석에 사용하지 않는다.

## 3. 수정 사항

- 계정명 부분 문자열 검색 대신 표준계정 ID와 정확한 계정명 일치를 우선하도록 변경했다.
- 재무상태표(BS), 손익계산서(IS/CIS), 현금흐름표(CF)를 구분해 항목을 선택하도록 변경했다.
- 반기 손익계산서에는 누적 금액 필드를 우선 적용하도록 수정했다.
- 필수 재무 항목 누락, 자산총계와 부채·자본 합계의 불일치, 유동자산·유동부채 범위 오류를 검사한다.
- 검증을 통과하지 못한 행은 대시보드에 게시하지 않고, 보고서에 오류 사유를 기록하도록 했다.

## 4. 분석 결과

**수정된 데이터 파이프라인을 다시 실행하기 전까지 수치 기반 결론을 제시하지 않는다.** 검증을 통과한 연간 자료가 확보되면 보고서가 자동으로 갱신되며, 매출액·영업이익·순이익 추이와 영업이익률·부채비율·유동비율·ROE를 표로 제시한다.

## 5. 한계 및 후속 작업

- 2010~2014년 공시 원문 XML은 문서별 서식 차이가 있으므로 추출 결과를 원문과 대조해야 한다.
- 국내 비교기업 목록은 비교 후보이며, 현재 실제 기업별 재무 수치를 수집해 비교한 결과는 아니다.
- ROA와 ROE는 평균 자산·평균 자본을 사용하면 더 적절하므로 기말 잔액으로 계산한 비율은 근사치로 해석해야 한다.
- 본 보고서는 공시자료 기반 학습·분석용이며 투자 권유가 아니다.
